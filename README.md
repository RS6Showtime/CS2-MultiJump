# CS2-MultiJump

A counterstrikesharp plugin that allows players to multijump on the server.

# Issues
I'm sure a couple of problems are still running, but you can open an issue on this project.

# Configuration
After compiling or downloading the plugin completely, a json will be created in your configuration file.
```
configs/plugins/MultiJump/MultiJump.json
```

# Commands
There is a single command available, and it's used to reload the config. When you want to reload the value you just edited in the json file. (Can be used from the console by the server ONLY)
```
css_reloadconfig
```
